# Flower Shop - Assignment 002

A responsive landing page for a Flower Shop, developed as part of Assignment 002. This project showcases a beautiful layout for selling flowers, featuring various sections like a banner, featured products, latest deals, and a subscription form.

[Live Demo](https://websites0.github.io/Assignment-2/)

## Features

-   **Navbar**: Responsive navigation bar with logo and links.
-   **Banner Section**: Hero section with a welcome message and a call-to-action button.
-   **Featured Flowers**: A grid display of featured flower products with "Add to Cart" functionality.
-   **Latest Deals**: showcasing special offers.
-   **Hot Deal Section**: Highlighted special deal with a "Trusted" badge.
-   **Newsletter Subscription**: A section for users to subscribe to updates.
-   **Footer**: Simple footer with copyright information.
-   **Responsive Design**: Adapts to different screen sizes.

## Technologies Used

-   **HTML5**: For structure and semantic markup.
-   **CSS3**: For styling and layout (using Flexbox/Grid).
-   **JavaScript**: Basic interaction (alert on "Add to Cart").
