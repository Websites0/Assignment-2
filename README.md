# Flower Shop - Assignment 002

A responsive landing page for a Flower Shop, developed as part of Assignment 002. This project showcases a beautiful, modern layout for an online flower store, featuring various sections including a banner, featured products, latest deals, and a subscription form.

[Live Demo](https://websites0.github.io/Assignment-2/)

## Features

-   **Responsive Navigation Bar**: Includes a logo, navigation links, and a cart icon. Adapts to mobile screens.
-   **Hero Section**: Eye-catching banner with a welcome message and call-to-action.
-   **Featured Flowers**: A grid layout displaying featured products with "Add to Cart" functionality.
-   **Latest Deals**: A section highlighting current discounts and offers.
-   **Hot Deal Section**: Features a special offer with a "Trusted" badge animation.
-   **Newsletter Subscription**: An input form for users to subscribe to updates.
-   **Responsive Design**: The layout adjusts seamlessly for desktop, tablet, and mobile devices using CSS Media Queries.
-   **Interactive Elements**: Hover effects on buttons and cards, and a simple JavaScript alert for cart actions.

## Technologies Used

-   **HTML5**: Semantic markup for better structure and accessibility.
-   **CSS3**: Custom styling using Flexbox and CSS Grid.
    -   CSS Variables for consistent color theming.
    -   Media Queries for responsiveness.
-   **JavaScript**: Basic DOM interaction for the "Add to Cart" button.

## Installation

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd <project-folder>
    ```

## Usage

1.  Open the `index.html` file in any modern web browser (Chrome, Firefox, Safari, Edge).
2.  Explore the landing page sections.
3.  Resize the browser window to test the responsive design.
4.  Click "Add to Cart" buttons to see the interaction.
